## 🚀 Quick Start

### Prerequisites
- Rust & Anchor CLI installed
- Node.js 20+
- Solana CLI
- Wallet with SOL for testing

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/blune-nft.git
cd blune-nft

# Frontend setup
cd frontend
npm install

# Program setup
cd ../program
anchor build
